# 🧭 如何使用本站

## 学习路径（三遍法）

| 遍数 | 做法 | 目标 |
|---|---|---|
| 第 1 遍 | 按 WK1→WK9 顺序读讲解，重点看 ⚠️ 陷阱卡片、💡 记忆卡片和 🔍 读图指南 | 理解每个概念"是什么、为什么" |
| 第 2 遍 | 做每讲末尾的 📝 自测题，错的回原文定位 | 把"看懂"变成"能答" |
| 考前 | 过 ⚡ 考前冲刺 的陷阱总表 + [知识点总清单](/modules/checklist) 逐项打勾 | 零遗漏 |

## ✍️ 我的标记怎么用

1. **高亮**：鼠标选中任意文字 → 弹出工具条 → 点 4 色之一。
2. **备注**：选中后点 📝，或之后直接**点击已有高亮**补写/修改备注、删除标记。
3. **查看**：右下角「✏️ 我的标记」→ 面板按 **讲次分组** 列出全部标记，点击直接跳转到原文位置并闪烁提示。
4. **备份**：标记存在本机浏览器（localStorage）。换电脑前点面板里的「导出」存成 JSON 文件，新电脑点「导入」。
5. **建议用法**：第 1 遍时把没读懂的句子标黄、老师强调的考点标蓝、自己总结的口诀写进备注。

## 🔍 搜索

左上角搜索框支持全文搜索（中英文术语都能搜，如 "leakage"、"阈值"、"RLHF"）。

## 内容约定

- **英文术语**：考试原文出现的专业术语保留英文（如 *data leakage*、*recall*），解释用中文。
- **陷阱卡片 ⚠️**：判断题最常见的错误表述。
- **考试重点 🎯**：最可能直接考的原话/口诀。
- **读图指南 🔍**：考试给图让你解释时的答题模板。
- **Lab 关联 🧪**：lab/作业里印证该知识点的实证。

## 更新机制

课程后续讲义（WK10+）发布后会追加新模块页；本页结构与标记功能不受影响。若发现内容遗漏或错误，告诉我具体讲次和页码即可修订。
